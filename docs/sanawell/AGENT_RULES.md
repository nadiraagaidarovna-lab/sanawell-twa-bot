# SanaWell AI Agent Rules

1. Never redesign approved UI.
2. Never choose colors independently.
3. Never replace the official SanaWell AI logo.
4. Never fabricate user wellness data.
5. Never invent correlations or medical conclusions.
6. Preserve backend/API behavior unless a task explicitly changes it.
7. Check git status, branch and HEAD before every task.
8. Never discard or overwrite uncommitted work.
9. Work on one explicitly assigned task at a time.
10. Run the relevant build/tests before committing code changes.
11. Never deploy to Render.
12. The user performs Render Manual Deploy.
13. Product positioning is wellness, not medical diagnosis or treatment.
14. Example user name in SanaWell AI specifications and demo UI is “Надира”.
15. Visual design decisions come from the approved SanaWell AI specifications, not from the coding agent.
