# SanaWell AI — Approved Product Decisions

## Product

- Product name: SanaWell AI.
- Telegram Mini App for women 40+ going through peri/menopause-related changes.
- Current positioning: wellness product, NOT medical diagnosis or treatment.
- Core value: help a woman collect fragmented changes in wellbeing into one understandable picture and see her personal dynamics over time.
- Working concept: “Менопауза 360°”.
- Primary comparison is with the user’s own history, not population norms.

## Primary user hypothesis

Woman approximately 45–55 who experiences several wellbeing changes simultaneously, has already had a confusing journey searching for help, spends her own money on doctors/tests/information, and wants a digital tool that helps organize her state.

This is a working hypothesis based on 21 customer-development interviews, not a claim about the entire market.

## Core product loop

CHECK-IN → SEE CHANGE/PATTERN → UNDERSTAND → ONE USEFUL NEXT STEP → RETURN.

## Home

Home information architecture is APPROVED.

It must provide fast access to most important product functionality without unnecessary scrolling.

Approved Home blocks:

1. Greeting using example name “Надира”.
2. “Моё состояние”.
3. Personal short-term dynamics.
4. Primary CTA “Отметить самочувствие”.
5. “Мы заметили”.
6. “Сегодня для вас”.

No large decorative photo of a woman on Home.

2. Движение и сила

4. Гормональная и интимная гигиена / Менопауза 360°

## Check-in direction

Core daily dimensions:

- Сон
- Энергия
- Настроение
- Ясность / концентрация
- Приливы / ночная потливость

Optional observations can include:

- muscles/joints
- appetite/weight changes
- intimate discomfort
- urinary discomfort
- heartbeat sensations
- headache
- skin/hair
- libido changes
- cycle changes
- anxiety/irritability
- other

Numeric measurement is preferred over sliders for numeric dimensions.

Do NOT create:

- menopause severity percentage
- hormone balance score
- diagnostic score
- fake correlations

## Personal history

Approved concept:
“Моя история 360°”

SanaWell gradually builds the woman’s history from the data she already enters.

The product should help show what changed over 7 / 30 / later 90 days using factual descriptions of her own tracked data.

## Doctor preparation

Approved product direction:
“Подготовиться к врачу”

SanaWell may create a user-controlled summary of tracked wellbeing data for a selected period.

It organizes the user’s own observations and questions.
It does NOT diagnose, prescribe treatment, or instruct the doctor.

## Visual system

Approved direction:

- light
- calm
- premium
- warm
- supportive
- readable for women 40+
- warm ivory/off-white background
- white/warm-white cards
- sage primary accent
- soft peach/blush secondary accents
- dark charcoal text
- rounded cards
- subtle borders/shadows
- generous whitespace

Avoid:

- hospital/clinical aesthetic
- stereotypical pink design
- excessive gradients
- excessive glassmorphism
- dashboard overload
- tiny typography
- generic AI-generated visual style

## Brand rules

- Always spell “SanaWell AI”.
- Use the official user-provided SanaWell AI logo whenever the brand mark is shown.
- Never replace it with an invented icon or generic logo.
- Example user name in specs/demo UI: “Надира”.

## Development workflow

Visual/UX decisions are approved outside the coding agent.

Coding agents implement approved specifications mechanically.

Workflow:
approved UX → exact specification → implementation → build/test → commit/push → user manually deploys through Render → iPhone review.

Coding agents must never deploy to Render.
